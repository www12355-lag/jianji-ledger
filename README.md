# 简记

一个轻量的本地记账应用，支持 Android App 和手机网页。底部导航包含首页、明细、统计和功能：

- 首页显示当月结余、分类速记和最近记录。预算、计划、周期账目、项目、借还款和账本设置归入“功能”页的三个图标分类，点开分类后显示用途说明和对应操作。
- 明细可按月份或所有月份查看记录，支持编辑、搜索备注和按类别、来源、收支类型筛选。
- 统计展示当月收支、支出分类和近六个月趋势。

“记一笔”默认显示金额、日期、类别和账户，其余字段放入“更多选项”；保存按钮固定在表单底部。新账目会带出上次使用的账户，类别按最近 100 笔支出的使用频次排序。明细按天分组，展示每日及筛选结果的收支合计，并支持清空筛选。

功能页的每个分类只展示工具图标，点击具体工具后才展开用途和操作。首页在存在待确认周期账目、支付通知、达到预算上限或逾期待收款时显示一条待办入口。

订阅管理支持按周、按月和按年费用，可新建或将已有周期支出关联为订阅。订阅与周期账目使用同一条规则，避免重复入账；展示下次扣费日期和折合月度费用。暂停只停止本机提醒和预测，实际取消订阅须在支付平台处理。“移出订阅”会保留原周期账目。订阅随账本一同加密备份。

分类预算会显示各类别及已设预算的合计剩余额度；查看当前月时还会给出按剩余天数计算的每日参考金额。统计页新增月末回顾，比较上月净支出、最多支出的类别和超预算类别。

一笔支出可拆分到多个类别，各部分金额必须合计为原支出。支出记录可关联部分或全部退款；退款不算普通收入，会减少净支出和相应类别的预算占用。拆分支出可按类别分别记录退款。原支出存在关联退款时，需先处理退款才能删除或改变原支出类型。

“记一笔”按钮在三个页面均可使用，也可以为记录添加照片。Android 版可对选中的收据或网购截图做本机文字识别，建议金额和商户；识别结果需核对并手动保存。

Android 版可开启应用锁，使用系统指纹、面容或屏幕锁验证。周期账目可开启系统通知提醒；通知仍需在应用内确认后才入账。系统通知权限关闭或省电限制可能影响送达。

Android 版首页支持支付通知辅助记账。用户在系统设置中授予通知读取权限后，应用仅处理来自微信或支付宝、且明确包含付款成功和金额的通知，在本机保存平台、金额和时间作为待确认记录。点击确认后可修改金额、日期、分类、账户和备注，保存后才正式入账；也可忽略。通知读取权限在系统层面允许应用接收设备通知，请仅在信任本应用时开启。通知缺失、文案变化或多金额消息可能导致遗漏或误识别，因此需要逐笔核对；功能不读取历史账单，也不连接支付账户。网页版本不支持此功能。
出现不同金额的同一条通知会被跳过；短时间内同平台同金额的通知或已有记录会标记为疑似重复，仍由用户决定是否记入。

明细页支持导入支付宝和微信“用于个人对账”的 Excel（.xlsx）或 CSV 账单。选择文件后会在设备上预览，可逐笔取消导入、调整收支类型和支出分类；识别到退款或转账时默认标为“不计收支”，请在预览中核对后再导入。重复导入的同一平台订单会自动跳过。平台发送的加密 ZIP 需先用账单密码解压，再选择其中的表格文件。当前不直接读取 ZIP 或 PDF，也不会连接支付账户。旧版 .xls 文件需另存为 .xlsx。

导入预览还会将与手动账目同日、同金额、同收支类型的记录标为疑似重复，默认跳过；用户可将账单记录关联到已有手动账目，也可选择新增。预览支持筛选待核对和疑似重复项，并批量勾选当前显示的普通记录。首页可管理自定义分类、周期记账和加密备份。周期账目支持每周或每月，可编辑、暂停和删除；到期后需要用户手动确认才会记入。预算达到 80% 或超出时在首页提醒，设置预算时可复制上月尚未在本月设置的类别。

删除账目后会移到“最近删除”，可恢复或手动永久删除；照片会随账目一起保留，永久删除后清理。已有账目且超过设置的间隔未保存加密备份时，首页显示提醒；可选择 7、30 或 90 天。此提醒只在打开应用时显示，不发送系统通知。

加密备份包括账目、账户、导入分类规则、预算、分类、周期规则和图片，使用密码加密为 `.jianji` 文件。保存前会解密校验刚生成的备份；恢复先验证密码和内容，再由用户确认替换当前账本。Android 版使用系统文件选择器保存备份；网页下载备份文件。将文件复制到新手机后，可通过“备份与恢复”导入。当前备份文件上限为 50 MB。手动备份的密码不会保存在应用内，遗失后无法解密。

Android 版可选择系统文件目录并设置自动备份密码。密码由 Android Keystore 保护并保存在本机；应用运行时，账本发生改动后会延迟约 15 秒生成一个新的加密备份文件。自动备份目录中的旧文件不会自动删除，请定期整理。可选择网盘同步的目录，把文件传到其他设备后手动恢复；当前不会自动合并或双向同步多个设备的账本。备份失败会在“备份与恢复”中显示，请定期检查最近写入时间和实际文件。关闭自动备份不会删除已保存的文件。

“备份与恢复”还可导出 CSV 明文表格，包含账目、分类、金额、账户和备注，方便在电子表格中查看。CSV 不含图片，也不能用于简记恢复；请妥善保管。

应用在当前设备上的当前安装环境保存数据：Android 版账目与设置使用 SQLite，网页版使用 IndexedDB；照片仍使用 IndexedDB。升级时会把旧版 localStorage 账本迁入新数据库，成功校验后才清理旧副本。网页与 Android App 的数据互不相通。

账户可设置期初余额，手动账目和导入账目可指定账户；账户间转账不计入收支统计。账户名称只是记账标签，不会连接支付平台。账户对账可输入实际余额并查看差额；如确认无需补记，可二次点击将差额记为余额校正，不计入收支。最近一次余额校正可撤销。

首页可管理常用速记模板。点模板会预填金额、类别、账户和备注，核对保存后才入账。年度支出计划适合保险、年费、旅行等非月度支出，可设置目标与预计月份，手动记录预留金额；预留只是计划标签，不会扣减账户余额。关联类别后会显示该类别当年的总支出，便于比较，计划本身不自动付款。

商户分类规则会按商户或备注关键词匹配新导入的支出，预览时仍可逐笔修改。手动记账可填写商户并选择记住分类；以后再次输入相同商户时会给出分类建议，由用户确认采用。导入账单时也可逐笔勾选“记住商户分类”并编辑关键词。支付通知目前只保存平台、金额和时间，因此确认通知时可手动填写商户，无法从通知自动识别具体商家。

首页可在连续 3 天没有新收支记录时提示检查漏记。此提示只根据本机账目判断，不代表实际发生了交易；可以暂停一周，或在账本设置中关闭。

首页现金流日历按账户余额、未来已记账收支、一次性计划和周期账目预测未来 30 天每天的余额。一次性计划可编辑、标记完成或删除；计划本身不会自动入账。按账户筛选时只纳入分配到该账户的计划和账目。预测只反映已输入的信息，不会读取支付平台的未来交易。

项目标签可把旅行、装修等跨类别支出汇总到一起。一笔记录可加入多个项目，明细页可以按项目筛选；项目净支出包含退款抵扣。删除仍被账目引用的项目会被阻止。

账本设置中的“修改历史”保留最近 100 次账目变更，可撤销某笔账目的最近一次操作。撤销会检查记录是否仍处于当时状态，以及关联退款是否允许还原；旧图片不保存在历史中。借还款由专门页面管理，不在此处单独撤销。

“借出与待收款”记录借款人、到期日和分次还款。借出及收回改变指定账户余额，但不计入收支统计；可查看剩余待收款和逾期状态。没有选择账户的借还款不会影响具体账户余额。

分类图标来自 [Lucide](https://lucide.dev/)，按 ISC 许可证使用，许可证文件见 `assets/icons/LUCIDE-LICENSE.txt`。图标打包在应用内，无须联网加载。

## 使用

网页可直接打开根目录的 `index.html`，或通过 GitHub Pages 访问发布页面。根目录的 `index.html`、`app.js`、`bill-import.js`、`ledger-features.js`、`backup-tools.js`、`csv-export.js`、`ocr-tools.js`、`ledger-store.js`、`styles.css` 和 `assets/` 是网页发布文件；`dist/` 是打包进 Android App 的对应页面。修改页面后，需要同步 `dist/` 中的文件并运行 `npm run android:sync`，再构建 Android 包。

## 简记 2.1 · 账本小报

统计页新增“账本小报”，支持日报、周报和月报。周报按周一至周日，月报按自然月；当前周期仅统计到今天并在图片上标明截止日期，未来账目、已删除账目和不计收支记录不纳入报告。

可预览并导出 1080 × 1620 的 PNG 图片，提供奶油紫、薄荷绿、蜜桃橙三套配色和自定义标题前缀。小报包含收支汇总、净支出分类、记账笔数、记录天数、上一期对比以及根据汇总生成的趣味称号与总结。趣味称号仅供娱乐，不是对消费习惯的专业评价。

默认隐藏具体金额，分类名称也可隐藏；小报不包含商户、备注、账户、账目照片或交易明细。分类比例按退款抵扣后净额为正的类别计算；退款归入退款发生日期，可能使本期净支出为负。未记账不等于未消费，图片会说明仅反映已记账收支。

安卓通过系统文件选择器保存 PNG，可通过系统分享面板选择发送到其他应用；打开分享面板不代表已经发送，接收人由用户选择。网页支持下载图片，在浏览器支持文件分享时可打开系统分享面板。报告在本机生成，不上传账本数据。打开保存或分享窗口属于受控的外部流程，直接返回保留解锁状态；熄屏仍会锁定。

## 简记 2.2 · 好友圈

“功能 → 日常与往来 → 好友圈”新增内测账号、邀请码加好友和双方确认、日报/周报/月报主动分享、预算进度选填、鼓励互动、撤回和删除好友。默认隐藏具体金额及分类名称，分享时由本人勾选接收好友。好友不会自动看到完整账本，云端只保存账号、关系和主动分享的汇总。已有本地账本和备份流程继续使用，登录不会同步或覆盖账本。

Android 登录状态用 Keystore 加密，恢复码只显示一次。云服务采用 HTTPS，数据库文件不对公网开放，支持限流、密码哈希、权限校验、每日数据库备份和证书自动续期。管理员部署与备份说明见 `server/README.md`。

## 简记 2.3 · 我的与好友消息

底部新增“我的”，账号资料、好友申请与列表、消息、好友分享、自动分享和排行榜入口分别打开。账号可编辑昵称、个人介绍和头像颜色；原账号与好友关系继续使用。好友工具从功能页移到“我的”，首页不增加模块。

好友之间可互发文字消息，支持未读数、每次 50 条历史分页、发送失败保留草稿及重试去重。仅当前好友可查看和发送双方的消息，消息通过 HTTPS 传输并存储在私有服务器，不属于端到端加密。打开应用查看消息时每 15 秒检查更新，应用关闭时暂不提供推送通知。

自动分享默认关闭，可选择当前日报/周报/月报、具体接收好友、隐藏金额、隐藏分类和月度预算进度。设置按本机账号保存；成功保存账本后自动更新同一周期的小报，相同内容不重复上传。仅在应用已打开、已解锁并联网时执行，离线等待下次联网打开；应用完全关闭时不定时上传。新增好友不会自动加入接收名单，删除好友会从自动分享名单移除。关闭自动分享保留原分享；撤回当前自动分享的周期时同步关闭本机自动分享，避免再次发布。自动更新按设置替换该周期的内容和接收人。

排行榜先保留入口和说明页，没有默认排名指标或消费金额比较，等待产品规则确定后实现。

- “我的”显示完整账本上次备份时间、提醒状态及快捷备份入口，不需要登录好友账号即可使用。备份状态来自本机手动备份和自动加密备份记录，不把好友服务的数据库备份当作完整账本备份。换手机前仍需导出完整账本。

## 简记 2.5 · 记账之外的小目标

- 功能 → 预算与计划 → 想买清单：价格、理由和 24 小时／3 天／7 天冷静期，支持修改、已买、暂时不买和删除。放下的愿望预算按计划价格统计，不等于实际节省；不会自动记账。
- 功能 → 日常与往来 → AA 分账：无需好友或登录即可填写姓名，支持 2 至 20 人均分、自定义份额、垫付人、关联同金额已有支出和分次结算。均分余下的分按参与人顺序分配，份额合计严格等于总额。分摊和结算均不会转账或自动生成收支。
- 分摊参与人可选关联当前好友；发起人主动邀请，好友确认接收后可见完整分摊并提交自己的结算，发起人核对确认或拒绝。未接收的人只看到用途、日期、总额和自己的份额；私有好友备注和关联账目的备注／照片不上传。已分享的单据不再修改，可撤回后新建；登录原账号并联网查看最新结算。
- 我的 → 排行榜：自愿加入连续记账 7 天、30 天记账 20 天挑战，可邀请好友，也可独自参与。好友确认加入，开始日后不能中途加入；当天有已保存的收入／支出／退款时记录一天，不能补填或预填。只上传挑战日期，不上传账目和金额；本挑战已加入者可见昵称、天数、完成率和并列排名。
- 我的 → 加密云备份：默认关闭，手机端用备份密码加密完整账本后上传，云端仅保留最近一份、上限 20 MB，可选择包含照片。密码不会发送给服务器，Android 使用独立 Keystore 加密保存；网页仅在当前会话保留。自动备份仅在应用打开、已解锁、联网时每天最多一次，冲突版本需人工确认。恢复先下载解密预览，再确认替换；恢复或删除云端备份会暂停自动云备份。备份密码遗失无法恢复，仍建议另存本机备份。
- 统计 → 账本小报 → 年度回顾：导出 1080 × 2320 PNG，包含年度汇总、趣味称号、12 个月记录／净支出轨迹和本年达标的储蓄目标数量。当前年只统计到今天，默认隐藏具体金额，分类可选隐藏，不含备注、商户、账户和照片。

想买清单和本机 AA 分摊包含在原有加密备份中；好友消息、挑战和在线分摊由账号服务保存。年度回顾在本机生成，云备份与好友分享是独立开关，开启其中一个不会开启另一个。

## 简记 2.6 · 归物本

入口为“功能 → 日常与往来 → 归物本”，可搜索名称与留句话，按状态或物品类别筛选，按最近购入、购入价格、日均成本或陪伴时长排序。汇总随筛选变化，展示物品件数、购入总额及各物品日均成本之和；支持隐藏金额。首页保持原有布局。

物品记录包括名称、购入金额、购入日期、开始持有日期、在用／闲置／已卖出／已退役状态、结束日期和选填留句话。日均成本按购入金额除以持有天数，开始当天计为一天；按中国时区的日历日期计算，避免时差和当天除零。闲置继续累计，卖出或退役固定到结束日期。零元礼物也可记录。购入总额不是当前二手价值，日均成本不会计入每天的真实支出。

封面可选择 33 种离线 SVG 物品图标（手机、电脑、耳机、相机、家电、服饰、交通、运动、家居等），或拍照／相册图片。选图后在本机缩小至最长边 1400 像素，以 JPEG 保存，物品卡片显示照片。图标与照片可以切换。

可关联已有支出，带入金额、日期和图片，不会新增支出。关联图片保存为独立副本，之后修改或删除原账目不会丢失物品封面；双方金额和日期也不会互相自动修改。删除物品不删除原支出。

完整本机加密备份和含照片的云备份均包含归物本及封面，恢复时重新映射照片标识。云备份选择不含照片时，仅云端副本回退到所选内置图标，本机照片继续保留。归物本最多保留 1000 件物品；原有不含归物本的备份可以继续恢复。

含归物本照片的新备份应使用 2.6 或以上版本恢复；换设备前先更新目标设备的简记版本。

## 简记 2.7 · 归物本五项完善

- 物品删除移入回收站，照片、凭证、成本记录一起保留 30 天。删除后 8 秒可撤销，回收站支持恢复和永久删除；超过 30 天在打开应用、回到前台或打开回收站时清理。删除、卖出和退役物品停止生成售后提醒。原账目不受影响。
- 详情新增追加费用和回收金额，支持编辑、删除与关联已有支出／收入，同一账目在同一物品内仅计入一次。金额、日期以关联时的记录为准，后续不会自动跟随账目变化。净投入为购入＋追加费用－回收金额；列表和详情显示日均净成本，负值表示回收已超过投入，不是二手市场估值。各费用按发生日期纳入历史回顾。
- 编辑物品的“小目标与售后”可填写保修、下次保养日期、提前 0／1／3／7／14／30 天提醒，拍照或选择购买／保修凭证。Android 需开启系统提醒并允许通知，按北京时间约 9 点单次提醒；已进入提醒期且未过到期日的记录尽快提醒一次，去重后不会重复。通知只显示通用提示，不暴露名称或金额，实际投递受系统省电设置影响。网页在物品详情显示到期天数。
- 可设目标日均金额，按当前净成本和继续持有计算目标日期、剩余天数与进度。达到目标显示小成就卡入口；已卖出／退役但未达标时不再推算持续持有达标。追加费用或回收金额会重新计算目标进度。
- 归物本“物品回顾”支持陪伴最久、本年添置、年度回顾和日均小成就，勾选参与物品、三套配色、标题前缀，生成 PNG 保存或打开系统分享面板。默认隐藏金额、使用内置图标，物品照片需主动勾选；最多展示 6 件，汇总按勾选范围计算，不含留句话、费用明细或购买／保修凭证。年度陪伴天数是每件物品在本年持有天数之和，当前年只统计到今天。

本机和云端完整加密备份包含上述设置、回收站和凭证。恢复会重新映射封面及凭证照片标识；云备份取消包含照片时不上传封面和凭证，本机图片仍保留。含新凭证的备份应使用 2.7 或以上恢复。已通过成本／目标／回收站边界测试、Android 存储与凭证恢复、通知实际投递及单次去重、北京时间闹钟排程和分享隐私验证。
