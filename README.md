# 简记

一个轻量的本地记账应用，支持 Android App 和手机网页。底部导航包含首页、明细和统计：

- 首页显示当月结余、分类速记、分类预算、预算提醒、待确认的周期账目、备份提醒和最近记录。
- 明细可按月份或所有月份查看记录，支持编辑、搜索备注和按类别、来源、收支类型筛选。
- 统计展示当月收支、支出分类和近六个月趋势。

“记一笔”按钮在三个页面均可使用，也可以为记录添加照片。

明细页支持导入支付宝和微信“用于个人对账”的 Excel（.xlsx）或 CSV 账单。选择文件后会在设备上预览，可逐笔取消导入、调整收支类型和支出分类；识别到退款或转账时默认标为“不计收支”，请在预览中核对后再导入。重复导入的同一平台订单会自动跳过。平台发送的加密 ZIP 需先用账单密码解压，再选择其中的表格文件。当前不直接读取 ZIP 或 PDF，也不会连接支付账户。旧版 .xls 文件需另存为 .xlsx。

导入预览还会将与手动账目同日、同金额、同收支类型的记录标为疑似重复，默认跳过；用户可将账单记录关联到已有手动账目，也可选择新增。预览支持筛选待核对和疑似重复项，并批量勾选当前显示的普通记录。首页可管理自定义分类、周期记账和加密备份。周期账目支持每周或每月，可编辑、暂停和删除；到期后需要用户手动确认才会记入。预算达到 80% 或超出时在首页提醒，设置预算时可复制上月尚未在本月设置的类别。

删除账目后会移到“最近删除”，可恢复或手动永久删除；照片会随账目一起保留，永久删除后清理。已有账目且超过设置的间隔未保存加密备份时，首页显示提醒；可选择 7、30 或 90 天。此提醒只在打开应用时显示，不发送系统通知。

加密备份包括账目、账户、导入分类规则、预算、分类、周期规则和图片，使用密码加密为 `.jianji` 文件。保存前会解密校验刚生成的备份；恢复先验证密码和内容，再由用户确认替换当前账本。Android 版使用系统文件选择器保存备份；网页下载备份文件。将文件复制到新手机后，可通过“备份与恢复”导入。当前备份文件上限为 50 MB。密码不会保存在应用内，遗失后无法解密。

应用只在当前设备上的当前安装环境保存数据：Android 版账目与设置使用 SQLite，网页版使用 IndexedDB；照片仍使用 IndexedDB。升级时会把旧版 localStorage 账本迁入新数据库，成功校验后才清理旧副本。网页与 Android App 的数据互不相通，也不会自动同步到其他设备。

账户可设置期初余额，手动账目和导入账目可指定账户；账户间转账不计入收支统计。账户名称只是记账标签，不会连接支付平台。导入分类规则会按商户或备注关键词匹配新导入的支出，预览时仍可逐笔修改。

分类图标来自 [Lucide](https://lucide.dev/)，按 ISC 许可证使用，许可证文件见 `assets/icons/LUCIDE-LICENSE.txt`。图标打包在应用内，无须联网加载。

## 使用

网页可直接打开根目录的 `index.html`，或通过 GitHub Pages 访问发布页面。根目录的 `index.html`、`app.js`、`bill-import.js`、`ledger-features.js`、`backup-tools.js`、`ledger-store.js`、`styles.css` 和 `assets/` 是网页发布文件；`dist/` 是打包进 Android App 的对应页面。修改页面后，需要同步 `dist/` 中的文件并运行 `npm run android:sync`，再构建 Android 包。
